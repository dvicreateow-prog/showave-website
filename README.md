# SHOWAVE website

Public product website for SHOWAVE, powered by Afro Unity Group.

GitHub Pages serves this site at https://showave.afrounity.club/.
The desktop application source remains in a separate private repository.
Installers and checksums belong in https://github.com/dvicreateow-prog/showave-releases.

This repository contains the website only. Clean routes are directory index files. Browser drafts stay on the visitor's device. Community submissions, checkout, shared surveys and AI services are not connected.

The homepage visual code is an original SHOWAVE implementation. Chakra Petch is included under the SIL Open Font License in assets/CHAKRA-OFL.txt. The supplied SHOWAVE artwork identifies the project. Software components retain the licenses and notices included with each installer.

To preview locally, run `python -m http.server 8182 --bind 127.0.0.1` from this directory. No build dependencies or server-side services are required.

Update showave-assets/release-config.json after the corresponding public release assets and SHA-256 checksums have been verified.
