Audio Preferences

The audio tab presents you with options that control how audio should be output from Resolume.

Audio Output Device

0 ms
If an ASIO device is selected, an extra button is displayed that enables access to ASIO settings.

Output Channels

If you are using an audio device that supports more than two channels, you can choose the channels used for monitoring the preview audio.

Sample Rate

Higher sample rates provide higher quality audio but will require more processing, especially if audio effects are in use. 44100 is a good choice.

Buffer Size

Higher buffer sizes will introduce more latency into the system but setting the buffer size too low may cause glitches in the audio. 512 or 1024 are usually safe choices.

Audio Input Device

Audio FFT

50%
You can boost the gain if the signal is coming in too low.
TipYou can also set the FFT gain in the main interface via View > Show FFT Gain.

DMA Textures

Changes how Resolume sends your pixels from your computer’s hard drive to the graphic card. The recommended setting is Force ON. This is also the default. Only if you are experiencing performance problems on older or lower end GPUs, should you switch to Force OFF. Autodetect is a legacy setting.

Defaults

This section allows you to change several default settings to be used when importing files or creating a new composition.

Default Transport and Play Mode

Whatever you choose here will be the default setting for files that you import from that moment on. AV files or videos with a (silent) audio track will use the settings for audio. This does not affect clips that were already imported.

Default Blend Mode

Choose which Blend Mode newly created layers will use.

Tempo Nudge Range

25%
When nudging the BPM up or down, this sets what percentage of the current BPM it shifts the BPM up or down with. 10% is good when doing actual audio stuff; 25% is more suited when syncing visuals to music.
