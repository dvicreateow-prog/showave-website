OSC

Input

Before you start working with OSC, make sure that OSC Input is enabled and that you are on the same network and port as the device sending OSC to SHOWAVE Forge. To get OSC into SHOWAVE Forge use the OSC In node and connect it to the Read OSC node, then specify the address.

Output

Toggling Use Bundles packs all your messages together and sends them in one big bundle. Most OSC applications don't really care whether you send bundles or not, but some will prefer having it on or off. To get OSC out of SHOWAVE Forge use the Write OSC node in conjunction with the OSC Out node.

▶OSC Monitor

Here you can monitor the incoming OSC data. A browser page cannot open a UDP socket, so nothing can arrive on port 7100 in this window. SHOWAVE Forge lists every incoming address and its values here.

FFT

Spectrum In

A patch that contains the Spectrum In node will create a spectrum in tab in the effect, source or mixer you have made. This is a simple drop down menu where you can choose between local, show or external. If you choose local, the audio playing on the Clip will be used. If you choose show, all the audio playing in the Show will be used. If you choose external, the external FFT source set in the preferences will be used.

Frequency Bands

SHOWAVE Forge will receive the FFT data as an array of 1024 float values which each correspond to a frequency band. The lower the index, the lower the frequency. The width of each band is the sample rate divided by two, divided by 1024. The hearing limit of most adults is between 15khz and 17khz, so the highest indexes may be out of range and therefore less useful.
