Sending nothing is not a concept that exists in DMX, so the value set as Default is always sent. A Dimmer channel usually wants a Default of 255.

Only grid based distributions are supported. Having more than one pixel block is not supported.

Color Space

not supported
Full colour LEDs create colour from separate red, green and blue values. L sends the weighted luminance of the sampled pixel over a single channel; Alpha uses the presence of the content instead of its luminance. CMY is a 1:1 conversion from RGB. RGBW and RGBWA approximate the colour on the extra white and/or amber LEDs by dimming the other channels. Other colour spaces (16 bit, UV and other exotic types) are not supported.

Gamma Correction

For an unusual type of LED you can tweak this. Most of the time the default setting of 2.5 should be fine.
Updating a fixture that is already being used on the Input Selection stage updates all instances of the existing fixture as well. To make changes without affecting the current setup, make a duplicate of the fixture preset first.
